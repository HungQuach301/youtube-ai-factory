Canonical source: HungQuach301/youtube-ai-factory/main  
Uploaded copy purpose: Project orientation only  
Conflict rule: GitHub main wins  
Version: 2.0 — GitHub-first execution program

## 1. Program objective

Deliver two outcomes:

1. A reliable browser-operated YouTube production factory.
2. Real, rights-clean, measurable English-language videos for the US market.

The program is successful only when the factory can repeatedly publish and
learn from external signals at controlled cost.

## 11. Metrics update

Engineering metrics are updated through the same PR or structured deployment
receipt. Runtime audience metrics belong in measurement_daily.

Do not create a manual metrics commit after every deployment merely to record a
Sites version. The deployment receipt owns that identity.

Recommended METRICS.csv columns:

    date,published_videos,qualified_analytics_days,auth_gaps,unclassified_handlers,gates_implemented,gates_partial,gates_not_implemented,github_sites_drift,actual_spend_usd

## 12. Program stop rules

Stop and reassess when:

- production changes can bypass GitHub required checks;
- source-tree identity cannot be proven;
- unauthorized writes or secrets are exposed;
- provider spend is unreconciled;
- exact rights or lineage is absent;
- three repair loops fail for one WP;
- visual pilot remains below quality floor after two bounded treatment cycles;
- qualified external evidence contradicts the current content hypothesis.

Stopping means choosing a new evidence-backed hypothesis, not adding control
planes unrelated to the blocker.

# Production Method

Every stage must declare its input contract, bounded execution, required artifacts, independent critics, exit thresholds, rights/provenance controls, request envelope, failure route and downstream handoff.

## Stage completion bundle

- Stage contract and required artifacts
- Artifact SHA-256 and storage locations
- Evidence lineage and rights/provenance
- QA/eval result bound to exact artifact version
- Independent critic and unresolved dissent
- Request-level provider usage and cost
- Approval/freeze record

No UI status, plan, prompt, URL or verbal completion statement substitutes for this bundle.

## End-to-end production chain

```text
Audience need -> claim graph -> narrative -> narration -> visual intent
-> Channel Visual DNA -> Video Blueprint -> Shot Contracts
-> candidate tournament -> animatic -> qualified assets -> Scene Graph
-> integrated canary -> exact master -> AI assurance -> release
-> publication -> performance observation -> authorized learning promotion
```

Every step declares Definition of Ready, producer self-check, independent exit gate, root failure owner and typed downstream handoff. Upstream change makes only affected descendants stale. Repair creates at most one append-only root revision under the active authority; unchanged reruns and threshold weakening are forbidden.

Stage business logic never calls a provider directly. Paid work follows the Provider Gateway lifecycle in `DATA_PROVIDER_CONTROL_PLANE_V1`. Visual production follows `VISUAL_PRODUCTION_OPERATING_MODEL_V1`; master acceptance follows `AI_FIRST_PRODUCTION_ASSURANCE_V1` and `VIDEO_PRODUCTION_QUALITY_STANDARD_V3`.

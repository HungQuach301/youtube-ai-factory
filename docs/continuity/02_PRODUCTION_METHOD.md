# Production Method

Every stage must declare its input contract, bounded execution, required artifacts, independent critics, exit thresholds, rights/provenance controls, request envelope, failure route and downstream handoff.

## Stage completion bundle

- Stage contract and required artifacts
- Artifact SHA-256 and storage locations
- Evidence lineage and rights/provenance
- QA/eval result bound to exact artifact version
- Independent critic and unresolved dissent
- Request-level provider usage and cost
- Approval/freeze record

No UI status, plan, prompt, URL or verbal completion statement substitutes for this bundle.
